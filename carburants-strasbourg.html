Prix des carburants à Strasbourg, dans le 67 et le 68

Avant de faire le plein, compare. Strass Go affiche les prix des carburants dans le Bas-Rhin et le Haut-Rhin à partir des données publiques de l’État.

Ouvrir Strass Go

Une source officielle

Les prix proviennent de l’API gouvernementale Prix Carburants, un jeu de données ouvert alimenté par les stations-service. L’application n’invente aucun prix : elle affiche ce que la source fournit.

Comme les prix changent d’une station à l’autre, la comparaison peut représenter une vraie économie sur un plein.

Bas-Rhin et Haut-Rhin

La couverture comprend le Bas-Rhin (67), où se trouve Strasbourg, et le Haut-Rhin (68), utile si tu pars vers Colmar, Mulhouse ou le sud de l’Alsace.

Tu consultes la carte, tu repères les stations, et tu choisis en fonction de ton itinéraire.

Dans le même outil que le trafic

Tu peux enchaîner : vérifier le trafic Sirac, regarder les caméras sur ton axe, comparer les prix, lancer la navigation GPS 2D ou 3D. Pour la voiture comme pour la moto ou le scooter, tout est dans la même application.

Gratuit, sans publicité, sans compte, installable en PWA.
